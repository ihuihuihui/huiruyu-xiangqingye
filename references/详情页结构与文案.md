# 详情页结构与文案字段

## 默认 5 张主图

| 编号 | 任务 | 画面建议 | 文案字段 |
|---|---|---|---|
| H01 | Hero 首屏 | 产品最完整、最能识别的主视觉 | 主标题 / 一句核心理由 / 品牌与商品名 |
| H02 | IP/核心性格或第一卖点 | 角色气质、视觉记忆点或产品结果 | 主标题 / 副标题 / 短标签 |
| H03 | 实拍/证据 | 最终实物正面、侧面、背面或手持 | 主标题 / 实物说明 / 结构提示 |
| H04 | 使用场景 | 真实比例的门、包、桌面、车内等 | 主标题 / 场景收益 / 使用动作 |
| H05 | 礼赠/购买理由 | 送礼、收藏、节日或日常拥有场景 | 主标题 / 适合谁 / 单件或配件信息 |

主图不必都放完整规格；优先让用户停留、理解和点击。

## 默认 10 屏详情页

| 编号 | 屏幕目的 | 适合证明的内容 | 文案字段 |
|---|---|---|---|
| D01 | 承接首屏 | 产品身份和核心情绪 | 主标题 / 副标题 / 品牌商品名 |
| D02 | 顾虑引入 | 用户为什么会犹豫 | 主标题 / 痛点正文 / 画面说明 |
| D03 | IP或产品设定 | 性格、灵感、角色关系 | 主标题 / 性格关键词 / 小故事 |
| D04 | 使用场景 | 何时、何处、怎么使用 | 主标题 / 场景正文 / 尺度关系 |
| D05 | 结构/安装 | 连接、开合、收纳或使用方式 | 主标题 / 结构说明 / 动作提示 |
| D06 | 细节近看 | 面部、纹理、接口、做工等 | 主标题 / 细节标签 / 细节正文 |
| D07 | 材质与工艺 | 材质、颜色、制造方式和真实特征 | 主标题 / 材质副标题 / 适度工艺提示 |
| D08 | 尺寸与配件 | 高度、长宽、重量、配件 | 主标题 / 尺寸标注 / 配件说明 |
| D09 | 信息透明 | 单件/套装、实物范围、购买须知 | 主标题 / 清单 / 注意事项 |
| D10 | FAQ与收尾 | 消除最后顾虑、推动下单 | 主标题 / 2–4 个问答 / 收尾句 |

用户已指定屏幕方向时，保留指定方向，只优化画面和文案；不要为了套模板擅自换顺序。

## 文案规则

- 标题尽量短；一个屏幕只承担一个主要决策任务。
- 正文写消费者会感受到的结果、情绪或安心点，不写空泛的厂家说明。
- 规格、材料、尺寸、配件等事实必须和账本逐字一致。
- 绝对化、极限词、虚构背书、未经证实的对比、销量、评价和功效不进入最终稿。
- 有可见工艺特征的产品，把说明放在材质/购买须知的次级位置，避免把工艺提示变成首屏卖点。
- 文字必须与产品分离，优先使用大字号、留白和清晰层级；不要把小字堆在产品轮廓上。
