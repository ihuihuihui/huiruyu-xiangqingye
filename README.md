# huiruyu-xiangqingye

辉如雨详情页设计是一个面向 Codex 的通用电商视觉工作流 skill：从产品素材和用户需求出发，完成竞品结构拆解、用户痛点提炼、详情页框架、逐屏文案、AI 生图提示、视觉验收和交付整理。

它不绑定任何具体品牌、IP、产品、品类或项目，可用于潮玩、家居、数码、文创、服饰、美妆及其他需要主图和长详情页的商品。技能会区分实拍、渲染图、风格参考和过时素材，要求产品结构、配件、尺寸和使用方式以当前任务中已确认的事实为准。

## 安装

把这句话交给支持安装 Skill 的 Agent：

```text
请帮我安装这个 Skill：https://github.com/ihuihuihui/huiruyu-xiangqingye
```

或者在终端运行：

```bash
npx skills add ihuihuihui/huiruyu-xiangqingye
```

终端安装需要 Node.js（含 npx），默认安装到当前项目。如果希望 Codex 在所有项目中都能使用，在命令末尾加上 `--agent codex --global`。安装命令和选项见 [Skills CLI 官方说明](https://github.com/vercel-labs/skills#install-a-skill)。

仓库已包含 skill 所需的说明、模板、脚本和 MIT 许可证，无需另装外部 skill、Python 包或字体。装好后即可上传产品图，调用 `$huiruyu-xiangqingye` 开始制作；图片生成、图片查看和联网研究需要宿主 Agent 提供对应能力，详见下方运行依赖说明。

## 使用

在 Codex 中调用：

```text
$huiruyu-xiangqingye
```

例如：

> 使用 $huiruyu-xiangqingye，根据我上传的产品图制作小红书商品详情页。

默认工作流包括：

1. 平台与资料检查、缺项询问、产品身份和事实锁定
2. 竞品详情页结构拆解
3. 用户痛点与购买动机提炼
4. 页面框架与逐屏文案
5. Style Lock 与逐图生图提示
6. 每张都引用原始产品图，独立生成、逐图核对产品一致性和必要修正
7. 文件命名、验证报告和交付清单

仓库内的 `references/` 保存资料检查、单图模式、竞品研究、文案结构、视觉生成和验收模板；`scripts/validate_assets.py` 用 Python 标准库检查 PNG 数量、尺寸和比例，不能判断产品是否被改变。

## 建议提供的资料

资料越详细，越有利于准确还原产品和设计使用场景。建议提供：

- 目标平台与用途：商品主图、详情页或内容笔记，有无指定画幅和数量。
- 同一最终版本的产品图：正面/侧面/背面等多视角效果图、细节图、实拍图；已有角度即可先提交。
- 尺寸图或明确的尺寸数值（单位、顺序及是否含配件），材质和工艺说明。
- 产品作用、使用方式、适用场景、配件、单件/套装信息。

缺资料时 skill 会说明哪些模块受影响，并询问是否补充，或允许基于现有素材做受限创作。已经确认过的信息不会重复询问。涉及当前平台规则时核对官方来源；设计建议与已核验规则分开记录。

## 只有一张图也可以开始

允许按现有素材创作后，skill 会沿用原图可见外观，通过背景、光影、排版和经确认的场景丰富页面；不会为凑数量发明背面、隐藏结构、功能、配件、材质或尺寸。图片参数缺失时先做相关模块的草稿或替换为有证据的内容。

每次生成与修正都引用原始产品图。已有生成图只能辅助风格，不能取代产品原图。轮廓、比例、部件、连接、标识或表面发生偏离的图不进入成品交付；两次修正仍不通过则报告缺项、调整构图或请求补充素材。生成模型不能保证绝对还原，这套流程通过限制未知展示和逐图验收减少漂移。

## 运行依赖说明

本仓库没有需要通过 pip、npm 或其他包管理器安装的运行依赖。

- `scripts/validate_assets.py` 只使用 Python 3 标准库。
- 图像生成、图片查看和联网研究由 Codex 当前运行环境提供，不属于本仓库的第三方依赖；是否可用取决于宿主支持、账户权限与服务条款，仓库的 MIT 许可不授予这些服务的使用权。
- 如果当前运行环境暂不支持某项能力，skill 会输出可执行的 Prompt、研究表和验收记录，不会把未执行的动作写成已完成。

更详细的边界和许可说明见 [DEPENDENCIES.md](DEPENDENCIES.md)。

## 事实与视觉原则

- 产品实拍优先于效果图，用于锁定真实结构、配件、连接方式和表面状态。
- 先锁定同一版本/SKU；出现资料冲突时询问，不把不同产品混成一个新造型。
- 每张成品直接与原始产品图核对；不能只与其他生成图比较。
- 风格参考只学习版式、光影、色彩和信息组织，不复制品牌、文案或未经授权的画面。
- 用户要求成品图时，每张最终图独立生成并单独验收，不能用本地拼贴代替成品图。
- 具体材质、工艺特征、尺寸和使用限制只按当前任务的事实账本表达。
- 没有真实评价、销量、认证或背书证据时，不把推测写成事实。
